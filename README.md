# Maze Generator

A simple maze generation windows form app using various maze generating algorithms

Currently Includes:
- Binary Tree Generation
- Iterative Backtracking Generation
- Randomized Iterative Kurskal's Generation
- Depth First Search Solving Algorithm
- Generation Algorithm Dropdown Menu
- Advanced Options Menu

Planned Features:
- Maze Size Presets
